# Mathe-Spiele 🎮

HTML5-Lernspiele für den Matheunterricht – offline im Browser lauffähig, touch-optimiert, im 3Blue1Brown-Stil mit Retrowave-Akzenten. Zielgruppe: Schüler:innen der gymnasialen Oberstufe und Patenkinder.

## Spiele

### Mathe-Racer (Retrowave) 🏁
[`Mathe_Racer_Retrowave.html`](Mathe_Racer_Retrowave.html) – Mathe-Aufgaben als Rennen im Retrowave-Look: richtige Antworten geben Tempo, Fehler kosten Zeit. Mit Partikel-Effekten, Flash und Shake.

### Rechen-Schlange V2 🐍
[`Rechen_Schlange_V2.html`](Rechen_Schlange_V2.html) – Snake im 3B1B-Design mit großem Touch-D-Pad: Rechenaufgaben lösen, um zu wachsen. Die Vorlage für Struktur und Steuerung weiterer Apps.

## Nutzung

Einfach die jeweilige HTML-Datei herunterladen und im Browser (auch mobil, offline) öffnen. Kein Server, keine Installation, keine Abhängigkeiten – jede Datei ist ein komplettes Spiel.

## Design-Konventionen

- Hintergrund `#0a0c10`, Flächen `#0e1218` / `#12161d`, Text linksbündig
- Retrowave-Akzente: Pink `#ff4fd8`, Cyan `#35e0ff`, Violett `#B18CD9`
- Touch-optimiert (D-Pad / große Buttons)
- LaTeX direkt im HTML, keine externen Loader (Offline-Fähigkeit)
